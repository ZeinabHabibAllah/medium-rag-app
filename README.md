# Medium RAG App

A Retrieval-Augmented Generation (RAG) application that answers questions based on Medium articles.

## Overview

This project processes Medium article content, splits it into chunks, creates embeddings, retrieves the most relevant context, and generates grounded answers using an LLM API.

## Features

* Article-based question answering
* Document chunking
* Embedding-based retrieval
* Context retrieval for user queries
* LLM-generated answers
* API test form
* Deployed web app

## Technologies

* TypeScript
* Next.js
* RAG
* Embeddings
* LLM API
* Vercel
